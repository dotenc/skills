# Modern plugin logo

Created with the built-in OpenAI image generation tool. The PNG is saved at
`plugins/dotenc/assets/logo-modern.png` and referenced by both plugin image fields.
The superseded SVG assets have been removed from the plugin package.

The 1254 x 1254 PNG has an alpha channel. Visual inspection in a browser
confirmed readability at 24, 32, 48, and 64 pixels on white and dark navy
backgrounds. Plugin validation and package checks passed.

Open [the local preview](logo-preview.html) to inspect the logo in both themes.

## Generation prompt

Use case: logo-brand.
Create a completely new, polished modern logo icon for dotenc, an open-source developer tool for encrypted .env files using SSH keys. This is the final production app/plugin icon, not a presentation sheet or mockup.
Design: an ownable minimalist geometric symbol: two bold, balanced, slightly rounded angular enclosure/bracket shapes protect one clear central circular dot. The silhouette should suggest a secure container and code syntax, with the dot as the memorable focal point. Three simple visual elements at most. Carefully optically balanced, generous negative space, thick shapes, extremely readable at 24px. Avoid a literal generic padlock, shield, key, circuit diagram, busy hexagon, letters or wordmark.
Color and surface: white enclosure shapes and a luminous mint dot, on a vivid rich cobalt-blue rounded-square tile with only a very restrained tonal blue gradient. The tile should occupy about 92% of a square canvas, with consistent small outer padding and transparent pixels outside the rounded corners. Keep the icon colorful and high-contrast so it works against both dark and light interfaces. No black artwork. Flat vector-like precision, crisp edges, no bevels, no 3D, no glow, no drop shadow, no texture.
Composition: one single centered square logo, symmetric visual weight, no captions, no grid, no alternate versions, no decorative scene. Output a high quality square PNG with real alpha transparency around the tile.
